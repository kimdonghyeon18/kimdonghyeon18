## 안녕하세요, 김동현입니다

AI 엔지니어 부트캠프에서 머신러닝과 딥러닝을 공부하고 있습니다.
모델을 돌려 보는 데서 멈추지 않고, **왜 그 방법을 골랐고 결과를 어떻게 믿을 수 있는지** 설명할 수 있는 엔지니어가 되려고 합니다.

### 이렇게 일합니다

- **기준선부터:** 단순한 규칙이나 모델의 점수를 먼저 재고, 그 점수를 넘는지로 개선 여부를 판단합니다.
- **한 번에 하나씩:** 같은 분할과 지표에서 한 요소씩 바꿔 비교합니다.
- **점수 뒤의 오답:** 전체 정확도보다 어떤 집단에서 예측이 틀렸는지를 먼저 봅니다.
- **한계도 기록:** 무엇이 안 됐고 다음에 무엇을 해 볼지까지 남깁니다.
